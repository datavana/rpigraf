# Add the epi_tbl class and make it remember its source

Add the epi_tbl class and make it remember its source

## Usage

``` r
.to_epitable(data, source = NULL, distinct = FALSE)
```

## Arguments

- data:

  A tibble

- source:

  A named vector of source parameters, containing endpount, parameters
  and database name

- distinct:

  Whether to return distinct rows only.
